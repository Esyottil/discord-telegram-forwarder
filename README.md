# Discord ↔ Telegram Forwarder

Браузерное расширение для двусторонней пересылки сообщений между Discord и Telegram.

## 🚀 Возможности

- **📨 Пересылка из Discord в Telegram**
  - Автоматическое обнаружение новых сообщений
  - Пересылка имени пользователя и времени
  - Фильтрация по ключевым словам
  - Красивое форматирование с эмодзи

- **💬 Ответы из Telegram в Discord**
  - Отправка сообщений из Telegram прямо в Discord
  - Автоматическое подтверждение отправки
  - Работа в реальном времени

- **⚙️ Гибкие настройки**
  - Включение/отключение пересылки
  - Настройка ключевых слов
  - Простая конфигурация бота

## 🛠 Установка

### 1. Создание Telegram бота

1. Найдите `@BotFather` в Telegram
2. Отправьте команду `/newbot`
3. Укажите имя и username для бота
4. Сохраните полученный токен

### 2. Получение Chat ID

1. Найдите `@userinfobot` в Telegram
2. Отправьте любое сообщение
3. Скопируйте ваш Chat ID

### 3. Установка расширения

1. Скачайте файлы расширения
2. Откройте `chrome://extensions/` в браузере
3. Включите "Режим разработчика"
4. Нажмите "Загрузить распакованное расширение"
5. Выберите папку с файлами расширения

### 4. Настройка

1. Нажмите на иконку расширения в браузере
2. Введите:
   - **Token бота** - из @BotFather
   - **ID чата** - ваш Chat ID
   - **Ключевые слова** (опционально) - для фильтрации
3. Нажмите "Сохранить настройки"

## 🔧 Конфигурация

### manifest.json
```json
{
  "manifest_version": 3,
  "name": "Discord Telegram Forwarder",
  "version": "1.0",
  "permissions": ["storage"],
  "host_permissions": [
    "https://discord.com/*",
    "https://api.telegram.org/*"
  ]
}
```

## 🎯 Использование
##Пересылка из Discord в Telegram

1. Откройте Discord в браузере
2. Расширение автоматически начнет отслеживать новые сообщения
3. Сообщения будут пересылаться в Telegram в формате:

```
👤 Username
🕒 10:30
💬 Текст сообщения
```
##Ответы из Telegram в Discord (WIP)
1. Напишите сообщение в чат с ботом в Telegram
2. Сообщение автоматически отправится в активную вкладку Discord
3. Вы получите подтверждение отправки

## ⚙️ Настройка фильтров
##Ключевые слова
+ Оставьте поле пустым для пересылки всех сообщений

+ Укажите слова через запятую: важное, срочно, alert

+ Сообщения будут фильтроваться по наличию этих слов

## 🔒 Безопасность
+ Токен бота хранится локально в браузере

+ Расширение работает только на discord.com

+ Не собирает личные данные пользователей

## 🐛 Устранение неполадок
## Сообщения не пересылаются

+ Проверьте настройки бота в Telegram

+ Убедитесь, что Chat ID указан правильно

+ Проверьте, включена ли пересылка в настройках

## Ответы не отправляются в Discord
+ Убедитесь, что Discord открыт в браузере

+ Проверьте активность вкладки Discord

+ Перезагрузите расширение

## Ошибки в консоли
+ Проверьте корректность токена и Chat ID

+ Убедитесь в наличии интернет-соединения
